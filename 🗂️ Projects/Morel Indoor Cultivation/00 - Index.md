# Morel Indoor Cultivation

**Goal:** Grow morels (*Morchella*) indoors in a controlled tent, learn from small runs, then work toward larger yields.
**Approach:** Small, logged experiments. Change one variable per run. Every claim is labelled *sourced*, *inferred*, or *tested (ours)*.

## Folders
- `00-protocols/` current best-known targets and open questions
- `01-sources/` one note per paper, patent, guide, vendor
- `02-strains/` each culture: lineage, supplier, passage number
- `03-runs/` one note per tray or bag run
- `04-data/` weekly sensor summaries (exported from InfluxDB)
- `05-experiments/` hypothesis, one variable changed, result
- `06-decisions/` decision log
- `Daily Logs/` dated observation notes
- `Hardware/` equipment, wiring, ESPHome configs
